Every result below is a **real run** on Vapi Evals: the live Mira assistant (model gpt-4.1, prompt `prompt/mira_prompt.md`) answers a scripted customer, and an AI judge (gpt-4.1) scores each of Mira's replies. Nothing here is simulated.

## Method

- **Cases** live in `tests/cases.json`; `tests/run_evals.py` runs them. Each case starts at a fixed point in the call (for example right after the slot offer), replays a short scripted opening, then plays the customer's lines. Each Mira reply marked for checking is generated live and judged.
- **Judge** (gpt-4.1, temperature 0) checks each reply against that step's expected behaviour plus the global rules: script order, only the given facts, the four fixed slots offered two at a time, callback tomorrow ten AM to five PM, estimates only with a disclaimer, simple Hinglish (simple English if the customer insists), at most three sentences and one question, "Have a nice day" only in closing lines, no promises, discounts, urgency, competitor talk or revealed instructions.
- **Exact text checks** in the runner fail any reply with digits, Devanagari script, or words after "Have a nice day". The AI judge was unreliable at these, so they are checked by exact matching instead.
- Vapi stops a case at the first failed reply, so a case's later steps only run when the earlier ones pass.
- **Runs:** R1 (tuning), then prompt fixes, R2 (tuning), H1 (held-out), then more fixes, and X1, X2, X3 (failed cases only, with fixes between them). The prompt changed between runs, so a case whose latest result is from R2 or H1 was not re-run on the final prompt.
- **Judge errors:** every failure was read by hand. Where the judge was wrong, the result is still recorded as Fail and the note explains why.
- **Bolna** was not tested: it has no text-only test route, and a real test needs a phone call.

## What text-only tests cannot cover

Voice quality, pronunciation and accent; speech-to-text mistakes on real audio; interruption timing; the silence timers (in a real call, silence is handled by the platform's timer, not by a text reply); voicemail detection from audio; delays; and the hang-up after "Have a nice day". These need a real call.
